# Мастерская мебели — Android

Приложение для базового проектирования корпусного шкафа, расчёта деталей, предварительного раскроя ЛДСП и экспорта ведомости/сводки в PDF.

## Сборка без компьютера

1. Создайте на GitHub новый пустой репозиторий.
2. Распакуйте архив на телефоне.
3. Загрузите **все файлы и папки** архива в корень репозитория (важно сохранить `.github/workflows/build-apk.yml`).
4. Откройте вкладку **Actions** в репозитории.
5. Если GitHub попросит разрешить Actions — нажмите **I understand my workflows, go ahead and enable them**.
6. Откройте workflow **Build Android APK** и нажмите **Run workflow**. Также сборка запускается автоматически при push в `main`.
7. После успешного выполнения откройте завершённый запуск → раздел **Artifacts** → `FurnitureDesigner-debug-apk` и скачайте ZIP с APK внутри.
8. Распакуйте ZIP и установите `app-debug.apk` на Android. При необходимости разрешите установку приложений из этого источника.

## Что реализовано

- Ввод ширины, высоты, глубины, толщины ЛДСП, количества полок и дверей.
- Расчёт боковин, верхней/нижней панели, полок, задней стенки и фасадов.
- Предварительное размещение деталей на листах с учётом пропила  и припуска на обрезку.
- Просмотр схемы раскладки и фасадного эскиза.
- Экспорт ведомости и сводки раскроя в PDF через системный диалог сохранения.

## Ограничения первой версии

- Эскиз — 2D фасад, а не полноценная редактируемая 3D CAD-модель.
- Карта раскроя — эвристический предварительный расчёт; не учитывает текстуру, направление волокон, дефекты, реальные ограничения форматно-раскроечного станка и порядок резов.
- Присадка, петли, направляющие, конфирматы, кромление по отдельным сторонам и DXF пока не реализованы.
- Формулы рассчитаны на простой корпус с накладными фасадами и требуют адаптации под конкретную конструкцию, способ установки задней стенки и технологию производства.
- Перед изготовлением обязательно проверьте чертёж и размеры.
